# rpi5os vision: план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** детектор власного предмета (YOLO11n → NCNN) з камерою IMX219 на Raspberry Pi OS, у Yocto-образі rpi5os 1.2.0 і в ROS 2 (камера → детектор → рішення).

**Architecture:** один Python-пакет `rpi5os_vision` (камера через `rpicam-vid`, ncnn-детектор, геометрія, метрики, MJPEG-стрім, CLI) використовується скриптом на RPi OS, у Yocto і ROS-нодами. Yocto отримує libcamera/`rpicam-apps` з `meta-raspberrypi`, власні рецепти ncnn, `rpi5os-vision`, ROS-пакетів і systemd-сервіс. Модель — три файли в `vision/models/current/`, з пріоритетом `/var/lib/rpi5os-vision/model/` на Pi.

**Tech Stack:** Python 3.12, numpy, OpenCV, ncnn 20260526 (PyPI `ncnn==1.0.20260526`), Ultralytics 8.4.182 (тільки ПК), ROS 2 Jazzy, Yocto 6.0.3 Wrynose + meta-raspberrypi + meta-ros, pytest.

**Spec:** [docs/specs/2026-10-18-vision-design.md](../specs/2026-10-18-vision-design.md)
